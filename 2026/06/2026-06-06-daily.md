# 观察者模式 (Observer Pattern)
#
# 适用场景：
# 1. 当一个对象（称为“主体”或“发布者”）的状态发生改变时，
#    需要通知其他一个或多个对象（称为“观察者”或“订阅者”），
#    并且我们不确定有多少个、具体是哪些观察者会收到通知时。
# 2. 当一个对象需要能够通知其他对象，而又不想知道这些对象的具体类时。
#    这实现了主体与观察者之间的松耦合。
# 3. 适用于事件驱动的系统、GUI框架（如按钮点击事件）、
#    消息队列、发布/订阅模型、响应式编程等场景
