# ## 设计模式：观察者模式 (Observer Pattern)
#
# ### 意图 (Intent)
# 定义一种对象间一对多的依赖关系，当一个对象（称为“主题”或“被观察者”）的状态发生改变时，
# 所有依赖于它的对象（称为“观察者”）都会得到通知并自动更新。
#
# ### 适用场景 (Applicability)
#
# 当以下情况出现时，观察者模式非常有用：
# 1.  **状态变化通知：** 当一个对象的内部状态发生改变时，需要通知系统中其他对象，并且这些被通知的对象不需要知道改变的具体细节，只需要知道“发生了变化”并作出响应
