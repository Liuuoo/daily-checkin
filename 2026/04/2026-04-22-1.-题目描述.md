### 1. 题目描述

给定一个无序的整数数组 `nums`，找到其中最长上升子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的一些元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的一个子序列。

**示例：**

```
输入：nums = [10, 9, 2, 5, 3, 7, 101, 18]
输出：4
解释：最长上升子序列是 [2, 3, 7, 101]，因此长度为 4 。

输入：nums = [0, 1, 0, 3, 2, 3]
输出：4
解释：最长上升子序列是 [0, 1, 2, 3]，因此长度为 4 。

输入：nums = [7, 7, 7, 7, 7, 7, 7]
输出：1
解释：最长上升子序列是 [7]，因此长度为 1 。
```

**约束：**

*   `1 <= nums.length <= 2500`
*   `-10^4 <= nums[i] <= 10^4`

### 2. 思路分析

最长上升子序列 (LIS) 是一个经典的动态规划问题。它有两种常见的动态规划解法：`O(n^2)` 和 `O(n log n)`。我们将重点分析并实现 `O(n log n)` 的高效解法。

**2.1 O(n^2) 动态规划 (基础方法)**

1.  **定义 `dp` 数组：**
    `dp[i]` 表示以 `nums[i]` 结尾的最长上升子序列的长度。

2.  **初始化：**
    每个元素自身都可以构成一个长度为 1 的上升子序列，所以 `dp` 数组所有元素初始化为 1。

3.  **状态转移：**
    对于 `nums` 中的每个元素 `nums[i]` (从左到右遍历)：
    *   遍历其之前的所有元素 `nums[j]` (其中 `j < i`)。
    *   如果 `nums[i] > nums[j]`，这意味着 `nums[i]` 可以接在以 `nums[j]` 结尾的上升子序列之后，形成一个更长的上升子序列。
    *   因此，`dp[i]` 可以更新为 `max(dp[i], 1 + dp[j])`。

4.  **结果：**
    遍历完所有元素后，`dp` 数组中的最大值就是整个数组的最长上升子序列的长度。

**2.2 O(n log n) 动态规划 (优化方法)**

这个方法利用了“耐心排序”的思想，通常使用一个辅助数组 `tails` 来实现。

1.  **定义 `tails` 数组：**
    `tails[i]` 存储所有长度为 `i+1` 的上升子序列中，最小的那个结尾元素。
    这个 `tails` 数组的关键性质是：它将始终保持严格单调递增。

2.  **遍历 `nums` 数组：**
    对于 `nums` 中的每个数字 `num`：

    *   **情况 1：`num` 大于 `tails` 数组中的所有元素。**
        这意味着 `num` 可以延长目前已知的最长上升子序列。我们将 `num` 添加到 `tails` 数组的末尾。此时，LIS 的长度增加了 1。

    *   **情况 2：`num` 不大于 `tails` 数组中的所有元素。**
        这意味着 `num` 可以替换 `tails` 数组中的某个元素，从而形成一个长度相同但结尾元素更小的上升子序列。为了未来的扩展性，我们总是希望子序列的结尾元素尽可能小。
        我们需要在 `tails` 数组中找到第一个大于或等于 `num` 的元素 `tails[k]`，并将其替换为 `num`。
        由于 `tails` 数组是单调递增的，我们可以使用二分查找（`bisect_left`）来高效地找到这个位置 `k`。

3.  **结果：**
    遍历完 `nums` 数组后，`tails` 数组的长度就是最长上升子序列的长度。

**为什么 `tails` 数组是单调递增的？**
假设 `tails[i]` 是长度为 `i+1` 的子序列的最小结尾元素，`tails[j]` 是长度为 `j+1` 的子序列的最小结尾元素，且 `i < j`。如果 `tails[i] >= tails[j]`，那么我们可以取以 `tails[j]` 结尾的长度为 `j+1` 的子序列，然后去掉其最后一个元素，得到一个长度为 `j` 的子序列，其结尾元素小于 `tails[j]`。如果 `j = i+1`，那么我们找到了一个长度为 `i+1` 的子序列，其结尾元素小于 `tails[i]`，这与 `tails[i]` 是长度为 `i+1` 的子序列的最小结尾元素的定义矛盾。因此，`tails` 数组必须是单调递增的。

**示例追踪 `nums = [10, 9, 2, 5, 3, 7, 101, 18]`：**

| `num` | `tails` 数组操作                                   | `tails` 数组状态              | LIS 长度 (`len(tails)`) |
| :---- | :------------------------------------------------- | :-------------------------- | :-------------------- |
| `10`  | `num` 比 `tails` 都大，追加                         | `[10]`                      | `1`                   |
| `9`   | `9` < `10`，替换 `10` (`idx=0`)                    | `[9]`                       | `1`                   |
| `2`   | `2` < `9`，替换 `9` (`idx=0`)                      | `[2]`                       | `1`                   |
| `5`   | `5` > `2`，追加                                     | `[2, 5]`                    | `2`                   |
| `3`   | `3` 介于 `2` 和 `5` 之间，替换 `5` (`idx=1`)       | `[2, 3]`                    | `2`                   |
| `7`   | `7` > `3`，追加                                     | `[2, 3, 7]`                 | `3`                   |
| `101` | `101` > `7`，追加                                   | `[2, 3, 7, 101]`            | `4`                   |
| `18`  | `18` 介于 `7` 和 `101` 之间，替换 `101` (`idx=3`) | `[2, 3, 7, 18]`             | `4`                   |

最终 `tails` 数组的长度为 4，即最长上升子序列的长度。

### 3. 完整的Python代码实现

```python
import bisect

class Solution:
    def lengthOfLIS(self, nums: list[int]) -> int:
        # 处理空数组的边缘情况，如果数组为空，LIS长度为0
        if not nums:
            return 0

        # tails[i] 存储所有长度为 i+1 的上升子序列中，最小的那个结尾元素。
        # 这个 tails 数组将始终保持严格单调递增。
        tails = []

        # 遍历输入数组中的每一个数字
        for num in nums:
            # 使用 bisect_left 查找 num 在 tails 数组中的插入位置。
            # bisect_left(a, x) 返回一个索引 idx，使得所有 a[i] < x 的 i 都位于 idx 之前，
            # 并且所有 a[i] >= x 的 i 都位于 idx 之后。
            # 简单来说，它返回第一个大于或等于 num 的元素的索引。
            idx = bisect.bisect_left(tails, num)

            # 情况 1：如果 idx 等于 tails 的长度，说明 num 大于 tails 中所有元素。
            # 这意味着 num 可以延长当前最长的上升子序列。
            # 将 num 添加到 tails 数组的末尾，LIS 的长度增加 1。
            if idx == len(tails):
                tails.append(num)
            # 情况 2：如果 idx 小于 tails 的长度，说明 num 不大于 tails 中所有元素。
            # 此时，num 可以替换 tails[idx] (即 tails 中第一个大于或等于 num 的元素)。
            # 这样做是为了形成一个长度相同但结尾元素更小的上升子序列。
            # 更小的结尾元素为未来的数字提供了更多的扩展机会，从而可能找到更长的 LIS。
            # 注意：tails 数组本身并不是 LIS，但其长度是 LIS 的长度。
            else:
                tails[idx] = num
        
        # 遍历结束后，tails 数组的长度就是最长上升子序列的长度。
        return len(tails)

```

### 4. 时间和空间复杂度分析

*   **时间复杂度：`O(n log n)`**
    *   我们遍历了输入数组 `nums` 中的每一个元素，这一步是 `O(n)`。
    *   在每次循环中，我们调用 `bisect.bisect_left` 函数。`bisect_left` 函数在长度为 `k` 的有序列表中执行二分查找，其时间复杂度为 `O(log k)`。
    *   在最坏的情况下，`tails` 数组的长度可以增长到 `n`（例如，当输入数组本身就是严格递增的）。因此，每次二分查找的时间复杂度最坏为 `O(log n)`。
    *   综合起来，总的时间复杂度为 `O(n * log n)`。

*   **空间复杂度：`O(n)`**
    *   我们使用了一个额外的 `tails` 数组来存储子序列的最小结尾元素。
    *   在最坏的情况下（例如，当输入数组本身就是严格递增的），`tails` 数组会存储 `n` 个元素。
    *   因此，空间复杂度为 `O(n)`。
