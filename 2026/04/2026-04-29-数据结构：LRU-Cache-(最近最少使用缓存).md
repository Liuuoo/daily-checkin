### 数据结构：LRU Cache (最近最少使用缓存)

#### 1. 原理说明
LRU（Least Recently Used）缓存是一种常用的缓存淘汰算法。其核心思想是：**如果数据最近被访问过，那么将来被访问的几率也更高。**

为了实现 $O(1)$ 的查找和更新，我们通常结合使用两种数据结构：
*   **哈希表 (Hash Map/Dictionary)**：用于实现 $O(1)$ 的快速查找，存储 `Key` 到 `Node` 的映射。
*   **双向链表 (Doubly Linked List)**：用于维护数据的访问顺序。
    *   最近访问的节点放在链表头部（Head）。
    *   最久未访问的节点放在链表尾部（Tail）。
    *   当缓存满时，直接删除尾部节点。

#### 2. Python 实现

```python
class Node:
    """双向链表节点"""
    def __init__(self, key=0, value=0):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.hash_map = {}  # key -> Node
        # 使用哨兵节点简化边界条件处理
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node: Node):
        """从链表中移除节点"""
        prev_node = node.prev
        next_node = node.next
        prev_node.next = next_node
        next_node.prev = prev_node

    def _add_to_head(self, node: Node):
        """将节点添加到链表头部"""
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def get(self, key: int) -> int:
        if key in self.hash_map:
            node = self.hash_map[key]
            self._remove(node)
            self._add_to_head(node)
            return node.value
        return -1

    def put(self, key: int, value: int) -> None:
        if key in self.hash_map:
            # 更新已有节点
            node = self.hash_map[key]
            node.value = value
            self._remove(node)
            self._add_to_head(node)
        else:
            # 插入新节点
            if len(self.hash_map) >= self.capacity:
                # 淘汰最久未使用的节点 (tail的前一个)
                lru_node = self.tail.prev
                self._remove(lru_node)
                del self.hash_map[lru_node.key]
            
            new_node = Node(key, value)
            self.hash_map[key] = new_node
            self._add_to_head(new_node)
```

#### 3. 使用示例与测试

```python
# 测试逻辑
cache = LRUCache(2) # 容量为2

cache.put(1, 1)     # 缓存是 {1=1}
cache.put(2, 2)     # 缓存是 {1=1, 2=2}
print(cache.get(1)) # 返回 1，缓存是 {2=2, 1=1}
cache.put(3, 3)     # 淘汰 key 2，缓存是 {1=1, 3=3}
print(cache.get(2)) # 返回 -1 (未找到)
cache.put(4, 4)     # 淘汰 key 1，缓存是 {3=3, 4=4}
print(cache.get(1)) # 返回 -1 (未找到)
print(cache.get(3)) # 返回 3
print(cache.get(4)) # 返回 4
```

#### 4. 复杂度分析

| 操作 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **Get** | $O(1)$ | 字典查询为 $O(1)$，链表节点移动仅涉及指针重定向。 |
| **Put** | $O(1)$ | 字典插入/删除为 $O(1)$，链表节点增删为 $O(1)$。 |
| **空间复杂度** | $O(C)$ | $C$ 为缓存容量，需要存储 $C$ 个节点及其在哈希表中的引用。 |

**资深工程师贴士：**
在 Python 中，其实 `collections.OrderedDict` 已经内置了基于哈希表和双向链表的 LRU 特性。如果是在生产环境实现高性能缓存，推荐直接使用 `functools.lru_cache` 装饰器，它由 C 语言实现，性能极高。手动实现 LRU 的意义在于理解其底层指针操作以及在分布式系统（如 Redis 内存淘汰策略）中的设计思想。
