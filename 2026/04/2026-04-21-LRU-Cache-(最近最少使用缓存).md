## LRU Cache (最近最少使用缓存)

### 1. 数据结构名称和原理说明

```python
# LRU Cache (Least Recently Used Cache)
#
# 原理说明：
# LRU Cache 是一种常见的缓存淘汰策略，其核心思想是“如果一个数据在最近一段时间没有被访问，那么在未来它被访问的可能性也很小”。
# 当缓存达到其容量上限时，LRU 策略会淘汰最近最少使用的数据项，为新的数据腾出空间。
#
# 实现 LRU Cache 的关键在于如何在 O(1) 的时间复杂度内完成以下操作：
# 1. 查找（get）：判断一个数据是否存在于缓存中，如果存在则返回其值，并将其标记为“最近使用”。
# 2. 插入/更新（put）：将一个数据插入或更新到缓存中，并将其标记为“最近使用”。如果缓存已满，需要淘汰最不常用的数据。
#
# 为了达到 O(1) 的时间复杂度，LRU Cache 通常结合使用两种基本数据结构：
# 1. 哈希表 (Hash Map / Dictionary)：用于存储键值对 (key -> 节点引用)。
#    - 作用：提供 O(1) 平均时间复杂度的查找能力，快速定位到给定 key 对应的缓存项。
# 2. 双向链表 (Doubly Linked List)：用于维护缓存项的访问顺序。
#    - 作用：链表头部存储最近最常使用 (MRU) 的项，链表尾部存储最近最少使用 (LRU) 的项。
#    - 双向链表的特性使得在 O(1) 时间内可以：
#        - 将一个节点从链表中删除（已知节点引用）。
#        - 在链表头部或尾部添加节点。
#        - 将一个节点移动到链表头部（先删除再添加）。
#
# 结合方式：
# - 哈希表的键是缓存项的 key，值是双向链表中对应节点的引用。
# - 双向链表的节点存储缓存项的 key 和 value。
# - 为了简化链表操作中的边界条件（空链表、添加/删除头尾节点），通常会使用两个哑节点 (dummy head 和 dummy tail) 来标记链表的两端。
```

### 2. 完整的Python类实现

```python
# 双向链表节点定义
class Node:
    """
    双向链表节点，用于存储缓存项的 key 和 value，并维护前后节点的引用。
    """
    def __init__(self, key, value):
        self.key = key
        self.value = value
        self.prev = None  # 前一个节点
        self.next = None  # 后一个节点

class LRUCache:
    """
    LRU Cache 实现。
    结合哈希表和双向链表，提供 O(1) 平均时间复杂度的 get 和 put 操作。
    """
    def __init__(self, capacity: int):
        """
        初始化 LRU Cache。
        :param capacity: 缓存的最大容量。
        """
        if capacity <= 0:
            raise ValueError("缓存容量必须大于0")

        self.capacity = capacity
        self.size = 0  # 当前缓存中的元素数量
        self.cache = {}  # 哈希表，存储 key -> Node 对象

        # 使用哑节点 (dummy head 和 dummy tail) 简化链表操作。
        # head.next 永远指向最近最常使用的节点 (MRU)。
        # tail.prev 永远指向最近最少使用的节点 (LRU)。
        self.head = Node(0, 0)  # 哑头节点
        self.tail = Node(0, 0)  # 哑尾节点
        self.head.next = self.tail
        self.tail.prev = self.head

    def _add_node_to_front(self, node: Node):
        """
        将一个节点添加到双向链表的头部（即 head 之后），表示它最近被使用。
        :param node: 要添加的节点。
        """
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node
        self.size += 1

    def _remove_node(self, node: Node):
        """
        从双向链表中移除一个节点。
        :param node: 要移除的节点。
        """
        prev_node = node.prev
        next_node = node.next
        prev_node.next = next_node
        next_node.prev = prev_node
        self.size -= 1

    def _move_node_to_front(self, node: Node):
        """
        将一个已存在于链表中的节点移动到链表头部。
        这表示该节点最近被访问或修改。
        :param node: 要移动的节点。
        """
        self._remove_node(node)
        self._add_node_to_front(node)

    def get(self, key: int) -> int:
        """
        获取缓存中 key 对应的值。
        如果 key 存在，则返回其值，并将其标记为最近使用 (移动到链表头部)。
        如果 key 不存在，则返回 -1。
        :param key: 要查找的键。
        :return: 键对应的值，或 -1。
        """
        if key in self.cache:
            node = self.cache[key]
            # 访问后，将节点移动到链表头部，表示它最近被使用
            self._move_node_to_front(node)
            return node.value
        return -1

    def put(self, key: int, value: int) -> None:
        """
        将键值对放入缓存。
        如果 key 已存在，则更新其值，并将其标记为最近使用 (移动到链表头部)。
        如果 key 不存在：
            1. 创建新节点，添加到链表头部。
            2. 将新节点添加到哈希表。
            3. 如果此时缓存容量超出上限，则淘汰链表尾部的节点（最近最少使用），并从哈希表中移除。
        :param key: 要插入或更新的键。
        :param value: 要插入或更新的值。
        """
        if key in self.cache:
            node = self.cache[key]
            node.value = value  # 更新值
            self._move_node_to_front(node)  # 移动到链表头部
        else:
            new_node = Node(key, value)
            self.cache[key] = new_node
            self._add_node_to_front(new_node)  # 添加到链表头部

            # 检查容量是否超出
            if self.size > self.capacity:
                # 淘汰最近最少使用的节点（位于链表尾部，即 tail.prev）
                lru_node = self.tail.prev
                self._remove_node(lru_node)
                # 从哈希表中也移除该节点
                del self.cache[lru_node.key]

    def _get_current_cache_keys(self):
        """辅助方法：获取当前缓存中的所有键（按使用顺序，从MRU到LRU）"""
        keys = []
        current = self.head.next
        while current != self.tail:
            keys.append(current.key)
            current = current.next
        return keys

```

### 3. 使用示例和测试代码

```python
print("--- LRU Cache 测试示例 ---")

# 示例 1: 基本操作与淘汰

print("\n操作: lru_cache.put(1, 1)")
lru_cache.put(1, 1)  # 缓存: {1:1}  链表: (1)
print(f"当前缓存键 (MRU -> LRU): {lru_cache._get_current_cache_keys()}") # 预期: [1]

lru_cache.put(2, 2)  # 缓存: {1:1, 2:2} 链表: (2, 1)

print("\n操作: lru_cache.get(1)")
val_1 = lru_cache.get(1)  # 访问 1，1 变为 MRU。返回 1。
```

### 4. 复杂度分析

**时间复杂度 (Time Complexity):**

*   **`get(key)` 操作:**
    *   在哈希表 `self.cache` 中查找 `key`：平均时间复杂度为 **O(1)**。Python 内置字典的哈希查找通常非常高效，接近常数时间。
    *   如果找到 `key` 对应的节点：执行 `_move_node_to_front` 操作。这个操作包括 `_remove_node` 和 `_add_node_to_front`，都是对双向链表进行常数次指针修改，因此均为 **O(1)**。
    *   **总体而言，`get` 操作的平均时间复杂度为 O(1)。**

*   **`put(key, value)` 操作:**
    *   在哈希表 `self.cache` 中查找 `key`：平均时间复杂度为 **O(1)**。
    *   如果 `key` 已存在：更新节点值，并执行 `_move_node_to_front` 操作，耗时 **O(1)**。
    *   如果 `key` 不存在：
        *   创建新节点并将其添加到哈希表：**O(1)** 平均。
        *   执行 `_add_node_to_front` 操作，将新节点添加到链表头部：**O(1)**。
        *   如果容量超出，需要淘汰最旧的节点：从链表尾部移除节点 (`_remove_node`) 耗时 **O(1)**，并从哈希表删除对应条目耗时 **O(1)** 平均。
    *   **总体而言，`put` 操作的平均时间复杂度为 O(1)。**

**空间复杂度 (Space Complexity):**

*   **`self.cache` 哈希表：** 最多存储 `capacity` 个键值对，每个键值对存储一个 `key` 和一个 `Node` 对象的引用。
*   **双向链表：** 最多存储 `capacity` 个 `Node` 对象，以及两个哑节点 (`head` 和 `tail`)。
*   每个 `Node` 对象存储 `key`, `value` 以及两个指针 (`prev`, `next`)，占用常数大小的内存。
*   **因此，LRU Cache 的总空间复杂度与缓存容量成正比，为 O(capacity)。**
