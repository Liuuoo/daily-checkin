# 技巧名称：上下文管理器 (Context Managers)
# 简介：
# 上下文管理器是 Python 中用于管理资源（如文件、网络连接、数据库连接、锁等）
# 的一种强大机制。它允许你定义代码块进入和退出时的行为，确保资源在使用后被
# 妥善清理（释放），即使在代码块执行过程中发生异常。
#
# 实现方式：
# 1. 类实现：定义一个类，包含 `__enter__` 和 `__exit__` 特殊方法。
#    - `__enter__(self)`: 在进入 `with` 语句块之前执行。它负责设置上下文，
#      并返回一个对象（通常是 `self` 或被管理的资源对象），该对象可以通过 `with ... as ...` 语句捕获。
#    - `__exit__(self, exc_type, exc_val, exc_tb)`: 在退出 `with` 语句块时执行，
#      无论是否发生异常。
#        - `exc_type`: 如果发生异常，则为异常类型；否则为 `None`。
#        - `exc_val`: 如果发生异常，则为异常实例；
