# 1. 技巧名称和简介
# 装饰器 (Decorators)
# 装饰器是一种Python中用于修改或增强函数或方法的强大机制。
# 它允许你在不改变函数/方法源代码的情况下，为其添加额外的功能，如日志记录、访问控制、性能度量、执行统计等。
# 装饰器本质上是一个接收函数作为参数并返回一个新的函数（通常是包装后的原函数）的可调用对象（函数或类）。
# Python通过 `@decorator_name` 语法糖简化了装饰器的使用。

# 2. 使用场景说明
# - 日志记录 (Logging): 在函数执行前后记录调用信息、参数、返回值或执行时间。
# - 访问控制
